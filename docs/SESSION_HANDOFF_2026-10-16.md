## How to build and deploy (short)
- **Android:** PC, `C:\Users\IdrZog_MEM\MemotopiaAndroidBuild`, `.\Build-AndroidAab-local.ps1 -VersionCode N`; check `Output\Memotopia-N.aab.build-summary.txt` (result Succeeded; the "errors=3" are Google resolver warnings; real compile errors show as `error CS` in `Output\unity-build.log`). Verify the signature with `keytool -printcert -jarfile`: SHA1 `D8:D9:9A:30:...`. Upload ONLY to the Memotopia app in Play (Memo Gym is a different app and key).
- **Keep two copies in sync:** repo `frontend` (iOS source) and the Android side copy `...\MemotopiaAndroidBuild\Project` (not a git repo). Different on purpose: `MyIAPManager.cs`, `PurchaseButton.cs`, `AuthView.cs`, `AndroidGoogleSignIn.cs`, `Plugins/Android/AndroidManifest.xml`, ProjectSettings.
- **iOS (Mac `idrizzogaj@192.168.1.209`, same network only):** sync `frontend/Assets` from the PC with `tar | ssh` EXCEPT `Assets/Editor` (the Mac's `MemotopiaBuild.cs` holds version/build number; copy `AchievementEvidenceValidation.cs` and any new validator separately). Set version/build in `Assets/Editor/MemotopiaBuild.cs`. Export: `/Applications/Unity/Hub/Editor/2019.3.12f1/Unity.app/Contents/MacOS/Unity -batchmode -nographics -quit -projectPath ~/Projects/memotopia/frontend -executeMethod MemotopiaBuild.BuildIOS -logFile ~/Projects/memotopia/ios-build/unity_build_<ver>_<build>.log` (4 validators run; wait for "Exiting batchmode successfully"; 0 `error CS`). After upload Apple processes 10-30 minutes; then in App Store Connect remove the old build from the version (red minus on hover), Add Build, choose the new one, Save, then Add for Review (Idriz decides).
