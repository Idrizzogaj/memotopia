## How to build
**iOS** (Mac `idrizzogaj@192.168.1.209`, only on the home LAN; Unity 2019.3.12f1, project `~/Projects/memotopia`): sync `frontend/Assets` with `tar -cf - Assets | ssh ... 'cd ~/Projects/memotopia/frontend && tar -xf -'`, then run `tools/ios-mac-scripts/export-<BUILD>.sh` and `compile-<BUILD>.sh` (they live in `~/Projects/memotopia/ios-build` on the Mac; make a new set by replacing the build number). The owner signs and installs himself in the Mac's Terminal: `cd ~ && bash ~/Projects/memotopia/ios-build/sign-install-<BUILD>.sh` (asks for the Mac password; never ask for or handle it). Keep >= 6 GB free on the Mac (delete old `ios-build/Sprint-*` exports and `iOS DeviceSupport` of old iOS versions; ask first).
**Android** (Windows PC, Unity 2022.3.62f2, separate staging project `C:\Users\IdrZog_MEM\MemotopiaAndroidBuild\Project`, NOT a git repo): copy changed files from `frontend/Assets` into the staging project (also files that returned to HEAD, e.g. PairsManager.cs), but keep the Android-specific files from `tools/android-staging-overrides/` (AuthView.cs, PurchaseButton.cs, AndroidManifest.xml, MemotopiaGoogle.androidlib, ProjectSettings, Packages). Then run `tools/build-and-asset-scripts/Build-AndroidAab-local.ps1 -VersionCode N` (next free code: 25). Signing material is in `C:\Users\IdrZog_MEM\.android-signing\memotopia` and is NEVER in git. Verify with `keytool -printcert -jarfile` (SHA1 above), then copy to Downloads. Android Plugins/Android jars/aars are not in git; the staging project holds them.
Unity code must compile on both 2019.3 (iOS) and 2022.3 (Android/staging); use `#if UNITY_2022_2_OR_NEWER` for newer APIs.
