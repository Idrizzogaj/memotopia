# Release tracks

After the current device build is ready, create `codex/focus-2.1.0` from the verified 2.0 baseline. Keep `codex/challenge-sprint-90` for 2.0 release fixes. The Focus branch targets 2.1.0; the user will supply three games. Do not enable Focus in the 2.0 branch or merge unfinished Focus work into it. Record the common commit when the branch is created; cherry-pick applicable release fixes into 2.1 as needed.
